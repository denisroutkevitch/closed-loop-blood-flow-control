# closed_loop_blood_flow_control

This repository contains three folders, each dedicated to a separate component
of this study. For any questions and assistance running the code, please
email Denis Routkevitch (droutke1@jhmi.edu or droutkev@uw.edu).

## Data

The datasets that accompany this code are hosted on figshare:

> DOI: `10.6084/m9.figshare.32521884`

Download and unzip the figshare archive, then point the `repo_path` variable in
both `preprocessing/setup_paths.m` and `analysis/setup_paths.m` at the resulting
data root. The code expects the following layout under `repo_path` (folders
marked *auto-created* are generated by the scripts and need not be present up
front):


### Adapting to a new dataset

A few values are tied to the specific subjects/sessions in the published data
and **must be re-set when running on new data**:

- `surgery_data.mat` - used in preprocessing step, may vary depending on recording setup
- Date-stamped data paths — `generate_controllers.m`, `define_average_TFs.m`,
  `Figure_2_evaluate_LBNP_TFs.m`, `Figure_3_evaluate_infusion_TFs.m`, and
  `Figure_4_simulations.m` reference dataset-specific folders/files such as
  `Rat System ID/Official TFs (240806)` and the controller filenames in
  `Feedback Control/Official Controllers/`. Re-point these to your dataset.
- `real_time_feedback_control.m` — `or_loc` selects an operating-room-specific
  PicoScope blood-pressure calibration. Set it (or add a new calibration) for
  your acquisition setup.

## real_time

This is the code used for data recording and running the real-time feedback
control experiments. Running this code with the appropriate hardware generates
a raw data folder, writing directly to disk as data are recorded.
Run `real_time_feedback_control.m` to start data collection.
I recommend clearing the Data folder between experiments, and saving the code 
used for each experiment to reference in the future.

Hardware requirements (detected automatically; dummy signals used if absent):
- PicoScope 2000 + MATLAB SDK (arterial blood pressure)
- Sound Blaster G3 USB audio card connected to a Doppler probe (flow velocity)
- Genie syringe pump on a serial COM port (drug infusion)

## preprocessing

This code converts raw data into a single usable `.mat` file for further
analysis. Before running, navigate to the `preprocessing/` folder and run
`setup_paths` once to configure the raw data and processed output directories.
Set the `repo_path` variable in `setup_paths` to your local data root (see
[Data](#data) for the source and expected layout).
Then use `compile_data_RT.m` to run through the entire preprocessing pipeline.

## analysis

This is the code used for all analysis and figure generation in the paper.
It also includes all the code necessary to generate a new controller. Before running,
navigate to the `analysis/` folder and run `setup_paths` once to configure the data and output directories.
Set the `repo_path` variable in `setup_paths` to your local data root (see
[Data](#data) for the source and expected layout).
Use `main_analysis_pipeline.m` as a guide for the order of scripts.

## Requirements

### Minimum MATLAB version
**MATLAB R2024a** or newer. The Simulink models (`H_inf_synth_model.slx`,
`simulate_controller.slx`) are saved in the R2024a format and will not open in
earlier releases, and the plotting code uses `hex2rgb`, which became a built-in
in R2024a. Several other functions set lower floors on individual scripts
(`uigridlayout` R2018b, `exportgraphics` R2020a), but R2024a is required to run
the pipeline as shipped.

### Required MATLAB Toolboxes
- Simulink — closed-loop controller simulations (`generate_controllers.m`, `Figure_4_simulations.m`, `simulate_timeseries.m`; requires `H_inf_synth_model.slx` and `simulate_controller.slx`)
- Simulink Control Design — linearizes the closed-loop model for H-infinity synthesis (`linearize`, `getlinio`, `operpoint` in `generate_controllers.m`)
- Robust Control Toolbox — H-infinity controller synthesis and loop-shaping weights (`hinfsyn`, `makeweight` in `generate_controllers.m`)
- Signal Processing Toolbox — filtering and envelope detection (`butter`, `filtfilt`)
- Control System Toolbox — transfer functions, PID, and simulation (`tf`, `ss`, `pid`, `feedback`, `bode`, `lsim`)
- System Identification Toolbox — data-driven transfer function estimation (`iddata`, `tfest`)
- Image Processing Toolbox — connected-component and morphological detection of challenge segments (`bwconncomp`, `imopen`, `strel` in the curation and real-time figure scripts)
- Audio Toolbox — real-time Doppler audio acquisition (`audioDeviceReader`)
- DSP System Toolbox — streams recorded Doppler audio to disk (`dsp.AudioFileWriter` in `real_time_feedback_control.m`)
- Parallel Computing Toolbox — accelerates the pole-zero grid search (`parfor` in `poles_zeros_search.m`; falls back to `for` if unavailable)

- PicoScope SDK (real-time code only): The real-time acquisition scripts use the [PicoScope MATLAB SDK](https://github.com/picotech/picosdk-matlab-picoscope) (`ps2000` instrument driver). Install it and ensure `picotech_ps2000_generic.mdd` is on your MATLAB path to run `real_time_feedback_control.m` unchanged.
